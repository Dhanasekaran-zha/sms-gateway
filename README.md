# Personal SMS Gateway — Antigravity Starter Kit

## How to use
1. Extract this folder.
2. Open the extracted folder in Google Antigravity.
3. Read `AGENTS.md` and `docs/IMPLEMENTATION_PLAN.md`.
4. Paste `prompts/00-BOOTSTRAP.md` into the agent.
5. Complete one phase at a time. Do not ask the agent to build everything in one pass.
6. Before changing agents, use `prompts/90-HANDOFF.md`; in the new agent use `prompts/91-RESUME.md`.

This is a private Android app that receives authenticated job notifications from your backend and sends SMS through the phone's SIM. Android SMS permission, carrier rules and applicable Indian messaging regulations still apply.
